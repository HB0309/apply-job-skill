# Track bases

One already-audited one-page résumé per track (`security.tex`, `software.tex`, `ai.tex`),
created with `python bin/jobkit.py base set <track> <application-folder>` from a tailored résumé you
approved. Prep starts from the matching base and edits it instead of rewriting from the pool.
`base list` shows which are stale (the pool changed after the base was set).
