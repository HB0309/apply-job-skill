# Q&A / Story Bank

> **Purpose:** ready-made answers to behavioural and application-form questions ("a challenge
> you faced", "something you're proud of", "a time you…"). Used to fill screener text boxes and
> to rehearse before interviews.
>
> **SEPARATION RULE (absolute):** this file is answer-only. Nothing here is a source for
> résumé bullets, the skills section, or the summary. Résumé facts trace to
> `master/content-pool.tex` + `master/profile.md` only. Stories may include detail and framing
> that would be too long for a résumé; that is fine, it stays here.
>
> **Format the tooling depends on:** `## <project or employer>` headings, then one
> `### Story <letter> — <angle>: <short title>` per story. `jobkit qa list` prints the `###`
> lines; `jobkit qa get "<substring>"` returns one story. Keep angles consistent so the skill
> can pick by angle: software · security · AI · systems · leadership · conflict · failure.
>
> **Usage rule:** a screener answer uses ONE story, at most two that complement each other.
> Never list every project.
